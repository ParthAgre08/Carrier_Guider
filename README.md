#  AI-Based Career Guidance Platform

A web-based platform that helps students make informed career decisions by analyzing their academic performance, personality (RIASEC), and interests.



##  Features

-  Personalized career recommendations  
-  Stream match scores  
-  Personality assessment  
-  Career roadmap generation  
-  “Why this career?” explanation  
-  Explore known and hidden career paths  



## ⚙️ How It Works

1. User selects education level  
2. Enters academic marks  
3. Completes personality assessment  
4. Selects interests  
5. System analyzes data and recommends best career paths  



## 🛠 Tech Stack

- Frontend: HTML, CSS, Tailwind CSS  
- Backend: Python, Flask  
- Database: SQL  
- Logic: Cosine Similarity & Weighted Scoring  

---

##  Impact

Helps students avoid blindly choosing a career path without understanding their strengths, and enables them to make informed decisions based on their abilities and interests.  


## About Platform 
A decision-support system that guides students towards better career choices with clarity and confidence.
